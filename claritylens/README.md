# ClarityLens — Smart Page Distiller & Focus Reader

ClarityLens is a lightweight, privacy-first Chrome Extension (Manifest V3) that turns overwhelming web pages into clear, scannable insights—100% locally in your browser with zero external API keys.

## Features
- **Instant Gist**: Extracts the top 4 key takeaways using client-side weighted term-frequency and position scoring, alongside reading time, word count, and Flesch-Kincaid grade level.
- **Core Concept Highlighter**: Identifies top topic keywords and highlights them directly on the page; click any keyword pill to jump straight to it.
- **Focus Reader**: Strips sidebars and clutter into a clean reading overlay with Paper, Sepia, and Night themes plus adjustable font size.
- **Reading Ruler (Spotlight)**: Dims surrounding text and creates a smooth horizontal spotlight band that follows your cursor.
- **Quick Clips**: Right-click any selected text (`Save snippet to ClarityLens`) or click `+ Clip Selection` to save quotes locally and export them as Markdown (`.md`).

## How to Install in Chrome
1. Unzip `claritylens-chrome-extension.zip` to a folder on your computer.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** and select the unzipped `claritylens` folder.
5. Pin **ClarityLens** from the puzzle-piece Extensions menu and click it on any article or webpage.
