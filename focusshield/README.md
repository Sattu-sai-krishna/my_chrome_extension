# FocusShield — Pomodoro Timer & Mindful Site Blocker

FocusShield is a calming, 100% local Chrome Extension (Manifest V3) that helps you protect deep work time.

## Features
- **Live Badge Countdown**: Run 25m Focus, 45m Deep Work, or 5m Break sessions with the remaining minutes shown right on the toolbar icon.
- **Mindful Site Blocker**: Automatically pauses distracting sites (customizable block list) while a Focus timer is running, with a calm redirect screen and a 2-minute emergency snooze.
- **Daily Focus Stats**: Tracks your completed sessions and focused minutes each day.

## How to Install in Chrome
1. Unzip `focusshield-chrome-extension.zip`.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the `focusshield` folder.
