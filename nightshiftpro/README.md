# NightShift Pro — Smart Dark Mode & Eye-Care Studio

NightShift Pro is a 100% local Chrome Extension (Manifest V3) inspired by Dark Reader that gives every website a clean, customizable dark theme.

## Features
- **Instant Anti-Flash Dark Mode**: Applies at `document_start` to prevent bright white page flashes.
- **Smart Media Preservation**: Automatically counter-inverts photos, videos, canvases, and background images so media looks natural.
- **3 Eye-Care Presets**: Switch between **Midnight**, **Warm Amber**, and **Soft Slate**.
- **Live Sliders & Per-Site Controls**: Adjust Brightness, Contrast, and Warmth in real time, or toggle dark mode on/off per website.

## How to Install in Chrome
1. Unzip `nightshiftpro-chrome-extension.zip`.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the `nightshiftpro` folder.
