# TabVault — Smart Tab Command Center & Workspaces

TabVault is a sleek, 100% local Chrome Extension (Manifest V3) built to solve browser tab overload.

## Features
- **Instant Cross-Window Search**: Filter every open tab across all Chrome windows by title or domain and jump to it in one click.
- **One-Click Auto-Group**: Clusters tabs from the same website into color-coded native Chrome Tab Groups.
- **Duplicate Tab Killer**: Detects and closes duplicate URLs with a single click.
- **Saved Workspaces**: Save your current window's tabs as a named workspace and reopen the entire session in a fresh window anytime.

## How to Install in Chrome
1. Unzip `tabvault-chrome-extension.zip`.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the `tabvault` folder.
