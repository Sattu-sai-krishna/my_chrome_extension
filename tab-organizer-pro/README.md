## 📦 Installation (30 seconds)

1. Open Chrome → `chrome://extensions/`
2. Toggle **Developer mode** ON (top right)
3. Click **Load unpacked**
4. Select this entire `tab-organizer-pro` folder
5. Extension icon appears! ✨

## 💻 How To Use

### 1. Organize Tabs
- Click the extension icon
- See all tabs automatically categorized (Work Tools, Research, Social, etc.)
- One-click navigation to any tab

### 2. Search Everything
- Type in the search box
- Instantly finds tabs by title or URL
- Works even with 100+ tabs

### 3. Reduce Memory
- Click "Close Inactive" to remove old tabs
- Background script auto-discards unused tabs
- Browser runs 3x faster!

### 4. Save Sessions
- Click "Save Session" to backup important tab collections
- Restore sessions later with one click

## 🚨 Troubleshooting

**Extension won't load?**
- Ensure Developer mode is ON
- Check all files are in same folder
- Clear Chrome extension cache

**Search not working?**
- Refresh the popup
- Ensure tabs have titles
- Check browser console for errors
