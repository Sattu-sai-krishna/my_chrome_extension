# TypeCraft — Smart Word Suggestions & Grammar Assistant

TypeCraft is a 100% local, privacy-first Chrome Extension (Manifest V3) that helps you write faster and more accurately on any webpage.

## Features
- **Instant Spelling & Typo Fixes**: Catches common typos (`recieve`, `definately`, `teh`, `dont`, `alot`) plus fuzzy Damerau-Levenshtein matching against a built-in English lexicon.
- **Grammar & Natural Phrasing Upgrades**: Suggests cleaner phrasing (`i am agree` → `I agree`, `more better` → `much better`, `could of` → `could have`, `discuss about` → `discuss`).
- **Smart Word Completion**: Suggests top matching words as you type 3+ letters—press **Tab** or click a chip to accept.
- **Live Test Pad & Personal Dictionary**: Test suggestions directly inside the extension popup and add custom words you never want flagged.

## How to Install in Chrome
1. Unzip `typecraft-chrome-extension.zip`.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the `typecraft` folder.
