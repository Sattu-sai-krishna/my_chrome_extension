# WebSlinger — Spider-Man Browser Companion

WebSlinger is a playful, 100% local Chrome Extension (Manifest V3) inspired by Spider-Man.

## Features
- **4 Spider-Suit Themes**: Switch the extension UI between **Classic**, **Symbiote**, **Iron**, and **Spider-Verse**.
- **Web-Shooter Mode**: Click anywhere on any webpage to shoot animated silk webs and leave web-splats.
- **Spidey-Sense**: Pulses a comic-book tingle border around the screen when hovering over external links.
- **Web-Swinger Mini-Game**: Swing between city rooftops in the popup arcade using `Space` or mouse clicks.

## How to Install in Chrome
1. Unzip `webslinger-spiderman-extension.zip`.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the `webslinger` folder.
